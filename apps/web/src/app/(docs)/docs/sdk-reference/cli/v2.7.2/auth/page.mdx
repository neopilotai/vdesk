## vdesk auth


authentication commands

### Usage

```bash
vdesk auth [options] [command]
```
## vdesk auth login


log in to CLI

### Usage

```bash
vdesk auth login [options]
```


## vdesk auth logout


log out of CLI

### Usage

```bash
vdesk auth logout [options]
```


## vdesk auth info


get information about the current user

### Usage

```bash
vdesk auth info [options]
```


## vdesk auth configure


configure user

### Usage

```bash
vdesk auth configure [options]
```
