# SDK Reference

This is the SDK reference for the [VDESKSK CLI & Core SDK](https://github.com/vdesk-dev/vdesk), [Code Interpreter SDK](https://github.com/vdesk-dev/code-interpreter), and [Desktop Sandbox SDK](https://github.com/vdesk-dev/desktop).

The reference is intended to be limited to low-level descriptions of various programmatic functionality. If you’re just getting started with VDESKSK, we would instead recommend looking at the [documentation](/docs) first or to get started quickly with an example.
